# خلاصة — لتلخيص المحاضرات والمذاكرة

تطبيق ويب مجاني لطلبة الجامعات والمدارس من **شاشا تك سوليوشنز**.
يلخّص المحاضرات، ويستخرج الأسئلة مع التصحيح الفوري، ويترجم المحاضرات والملفات، ويوفّر بطاقات مراجعة ومؤقت مذاكرة.
يُثبَّت على الهاتف ويعمل دون إنترنت.

## الميزات
- **الإدخال:** لصق نص، أو ملفات PDF وWord وPowerPoint (الجديدة والقديمة) وtxt، أو صور عبر التعرف الضوئي على النص (عربي وإنجليزي)، أو تسجيل صوتي.
- **التلخيص والأسئلة:** على الجهاز نفسه، دون إنترنت ودون إرسال أي بيانات.
- **الترجمة المجانية:** MyMemory دون مفتاح، أو Gemini بمفتاح مجاني، أو مترجم المتصفح المدمج.
- **التخزين:** كل البيانات محفوظة على جهاز الطالب فقط، مع نسخة احتياطية بصيغة JSON.

## النشر على GitHub Pages
1. ارفع هذه الملفات إلى مستودع على GitHub:
   - `index.html`
   - `sw.js`
   - `manifest.webmanifest`
   - مجلد `icons/`
2. افتح **Settings ← Pages**، واختر الفرع `main` والمجلد `/ (root)`، ثم اضغط **Save**.
3. بعد دقيقة يصبح التطبيق متاحاً على الرابط:
   `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

## التثبيت على الهاتف
- **Android:** افتح الرابط في Chrome، ثم اضغط زر «ثبّت خلاصة على هاتفك»، أو من القائمة ⋮ اختر «تثبيت التطبيق».
- **iPhone:** افتح الرابط في Safari، ثم اضغط زر المشاركة، واختر «إضافة إلى الشاشة الرئيسية».

بعد أول فتح يعمل التطبيق دون إنترنت.
أدوات قراءة ملفات PDF والصور تُحمَّل مرة واحدة عند أول استخدام، ثم تعمل دون إنترنت كذلك.

## الخصوصية
- لا يحتوي الكود على أي مفاتيح.
- مفاتيح الطالب، مثل مفتاح Gemini، تُحفظ في متصفحه فقط.
- لا يُرسل أي نص إلى خدمة خارجية إلا عند ضغط الطالب زر الترجمة أو الذكاء الاصطناعي، وبعد إعلامه.
